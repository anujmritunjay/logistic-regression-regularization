# Logistic Regression Regularization

This project explores **L1 (Lasso)** and **L2 (Ridge)** regularization in logistic regression from basic to advanced, with hands-on experiments.

## Goals
- Understand overfitting and why regularization helps
- Implement L1 and L2 regularized logistic regression
- Visualize how regularization impacts feature weights
- Tune regularization strength using cross-validation

## Contents
- 📘 Theory: Logistic Regression and Regularization
- 🧪 Experiments with Breast Cancer dataset
- 📊 Coefficient shrinkage visualizations
- 🔁 Regularization strength tuning
